# ADR-006: 권한 구분은 어떻게 할까요?

- 상태: 승인됨
- 날짜: 2026-11-15
- 요청: 엔터프라이즈급 쇼핑몰을 마이크로서비스로 만들어줘. 회원, 상품, 주문 서비스와 게이트웨이, 알림 워커로 나누고, 서비스마다 전용 DB를 써줘. 주문 알림은 Redis 대기열로 처리하고, 회원 정보와 주문 정보는 로그인한 사용자만 조회할 수 있게 만들어줘.

## 결정
**역할(USER/ADMIN) + 본인 소유 검사** — JWT에 role을 담고, 각 서비스가 본인 데이터 여부를 검사하며 상품 등록은 ADMIN만 허용

근거(장점):
- 단순하고 요구사항을 충족
- 관리자 기능 분리가 명확

## 검토한 대안
- 세분화 권한(Permission) RBAC (역할에 권한 목록(product:write 등)을 매핑) → 초기 설계·관리 부담 이유로 제외
- 정책 엔진(OPA 등) (중앙 정책 서버에서 접근을 판단) → 운영 복잡도와 지연 증가 이유로 제외

## 영향
접근 제어 규칙·관리자 기능 범위 · 감수: 세분화된 권한 추가 시 확장 필요
