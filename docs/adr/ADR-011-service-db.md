# ADR-011: 서비스별 전용 DB를 어떤 종류로 구성할까요?

- 상태: 승인됨
- 날짜: 2026-11-16
- 요청: 엔터프라이즈급 쇼핑몰을 마이크로서비스로 만들어줘. 회원, 상품, 주문 서비스와 게이트웨이, 알림 워커로 나누어주고, 서비스마다 전용 DB를 써줘. 주문 알림은 Redis 대기열로 처리하고, 회원 정보와 주문은 로그인한 사람만 조회 가능하게 만들어줘.

## 결정
**모든 서비스 PostgreSQL** — 서비스마다 별도 PostgreSQL 인스턴스/DB

근거(장점):
- 트랜잭션·일관성 강함
- 운영 도구 통일

## 검토한 대안
- PostgreSQL + MongoDB 혼합 (회원·주문은 PostgreSQL, 상품은 MongoDB) → DB 종류 증가로 운영 복잡 이유로 제외
- 모든 서비스 MySQL (서비스마다 별도 MySQL DB) → JSON·고급 기능은 PostgreSQL보다 약함 이유로 제외

## 영향
DB 컨테이너 구성, 트랜잭션·검색 특성, 운영 복잡도 · 감수: 상품 검색 유연성은 제한적
